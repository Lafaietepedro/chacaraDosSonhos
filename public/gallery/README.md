## Regras para novos assets

1. Não adicionar fotografia sem autor, URL de origem e licença verificáveis.
2. Não apresentar uma imagem ilustrativa como fotografia de cliente ou propriedade real.
3. Otimizar para web antes de versionar.
4. Preferir WebP, AVIF ou JPEG adequadamente comprimido.
5. Atualizar este arquivo na mesma alteração que adiciona o asset.
